# Manhunt

A real-world hide-and-seek game for phones. Seekers follow a live compass (or a street map) to each hider; hiders see what the host allows about the seekers. It's a web app, installable to the Home Screen, served from a Raspberry Pi through a Cloudflare tunnel.

Repository: `That-Coder-Guy/ManhuntApp` on GitHub. Work goes straight to `main`.
